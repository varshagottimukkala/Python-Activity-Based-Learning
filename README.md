## How to Run

Install Python 3, open a terminal in this repository and run a program. For example:

```bash
python3 02_electricity_billing/program.py
```

Enter the sample input given in that case study. If Python is installed as `python` on your computer, use `python` instead of `python3`.

The solutions use conditions, loops, strings, lists, nested lists and tuples. Where the question does not give rates or rules, the assumptions are stated in the case study. Output images are rendered from the recorded sample runs.
